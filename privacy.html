Privacy Policy

Last updated: 5 September 2026

1. Overview

Dhama ("the application") is a personal automation tool operated by a single individual. It is used to upload and manage video content on that individual's own YouTube channel. This policy explains what data the application accesses and how it is handled.

2. Who operates this application

Dhama is operated by an individual, not a company. Contact: ursula123539@gmail.com

3. Use of YouTube API Services

Dhama uses YouTube API Services. Specifically, it uses the YouTube Data API v3 to upload videos to, and manage content on, its operator's own YouTube channel.

By using Dhama you are agreeing to be bound by the YouTube Terms of Service.

Google's own handling of your information is described in the Google Privacy Policy, available at https://policies.google.com/privacy.

You can revoke Dhama's access to your data via the Google security settings page at https://myaccount.google.com/permissions.

4. What data is accessed

When the operator signs in with their Google Account, the application receives an OAuth access token and refresh token that allow it to act on that account's YouTube data. Using those tokens, the application may read and write:

  • Video files, titles, descriptions, tags and thumbnails
  • Playlists and playlist membership
  • Video privacy and publishing status
  • Basic channel identifiers needed to target the correct channel

The application requests only the youtube.upload and youtube.force-ssl scopes. It does not request or access Gmail, Google Drive, Contacts, Calendar, location data, or any Google data outside the YouTube scopes listed on the home page.

5. How data is used

Data is used solely to perform the action the operator initiated — uploading a video, updating its metadata, or organising playlists on their own channel. It is not used for advertising, profiling, analytics, model training, or any secondary purpose.

6. Storage and retention

OAuth tokens are stored locally on the operator's own machine or private server and are not transmitted to any third party. Video files processed by the application remain on that same machine. No user database is maintained, because the application has exactly one user: its operator.

Authorisation credentials are retained only for as long as the application is in active use. Any YouTube API data held temporarily in memory or in local working files is discarded once the upload it relates to has completed, and in no case is stored for longer than 30 days, in line with the YouTube API Services Terms of Service.

7. Deleting your data

The operator may delete all data held by the application at any time, and no request or waiting period is required:

  • Revoke the application's access at https://myaccount.google.com/permissions. This immediately and permanently invalidates the application's access and refresh tokens.
  • Delete the local token file and any local working files from the machine running the application. This removes every remaining copy of the authorisation data.

Because the application stores no data on any server and maintains no user database, these two steps remove all data the application holds. Questions about deletion can be sent to ursula123539@gmail.com.

8. Sharing

No data obtained through Google APIs is sold, rented, or shared with any third party. The only party the application transmits data to is Google itself, when carrying out the operator's requested YouTube actions.

9. Limited Use disclosure

Dhama's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

10. Security

Credentials and tokens are kept in local configuration that is not committed to public source control. All communication with Google APIs uses HTTPS.

11. Children

The application is not directed at children and is not made available to any user other than its operator.

12. Changes to this policy

If this policy changes, the updated version will be published at this URL with a revised "last updated" date.
